Санжаажамц Энхтайван — CV website
==================================

Файлууд:
- index.html : Вэб хуудасны бүтэц, CV-ийн агуулга
- styles.css : Responsive дизайн, хэвлэх/PDF загвар

Ашиглах:
1. index.html файлыг browser дээр нээнэ.
2. "CV татах" товчийг дарж Print цонх нээнэ.
3. Destination хэсгээс "Save as PDF" сонгон PDF болгон хадгална.

Өөрчлөх:
- index.html доторх текст, утас, имэйл, холбоосыг өөрчилж болно.
- styles.css дотор өнгө, зай, фонт, responsive тохиргоог өөрчилж болно.

Тэмдэглэл:
- Фонтын Google Fonts холбоос интернет шаарддаг. Интернетгүй үед системийн нөөц фонт ашиглана.
- Профайл зураг өгөөгүй тул нэрийн товчлол бүхий avatar ашигласан.
